# Clinical Evidence Assistant

A citation-grounded AI assistant for searching and answering questions about public clinical documents.

## Current status

- FastAPI application created
- Health endpoint implemented
- Automated health test implemented

## Retrieval evaluation

The project includes a reproducible synthetic clinical-document
evaluation.

Metrics:

- Hit@3: correct source page appears within the top three results
- MRR: mean reciprocal rank of the correct source page
